# Local datasets

Downloaded datasets and intermediate processing files belong here and are ignored
by Git. This README is tracked. Do not download data as part of repository setup.
Record dataset identity, version, provenance and processing steps in future run
metadata. No dataset specifications are assumed yet.

Reusable preparation code belongs in [ssta_model.data](../src/ssta_model/data/).
Small intentional test fixtures may be tracked under [tests/](../tests/); NetCDF
and CSV files are not globally ignored.
